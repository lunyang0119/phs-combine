## Combat 시스템 규칙 정리

이 코드는 **디스코드 봇 기반의 턴제 RPG 전투 시스템**으로, **Final Fantasy VII** 스타일의 전투 메커니즘을 구현하고 있습니다.

---

### 1. **전투 흐름 (Battle Flow)**

| 단계 | 설명 |
|------|------|
| **전투 초기화** | 참여자 캐시 생성, 난이도 설정, 환경 효과 결정 (20% 확률) |
| **턴 순서 결정** | **민첩(agility)** 높은 순 → 동점자는 무작위 |
| **턴 시작** | 현황 표시, 환경 효과 적용, 난입자 처리 |
| **행동** | 플레이어/몬스터가 순서대로 행동 |
| **턴 종료** | 환경 효과(마황 지대), 턴 카운트 증가 |
| **전투 종료** | 승리(모든 적 처치) 또는 패배(모든 아군 전투불능) |

---

### 2. **데미지 계산 규칙**

#### **물리 데미지 공식**
```
기본 데미지 = floor((근력-10)/2) + 2d10 + 5
```
- **스트라이커/솔져**: 최종 데미지 **1.5배**
- **잭스 버프(zack_buff)** 적용 시: 최종 데미지 **1.2배**

#### **마법 데미지/힐 공식**
```
power_half = max(5, round((파워-10)/2))
마법 위력 = round((마법-10)/2) + power_half + 1d(power_half) + 4
```
- **마테리아 위버/턱스**: 추가로 **+1d10**

#### **방어 감소량 공식**
```
감소량 = floor((근력-10)/2) + 1d11 + 4
```

---

### 3. **회피 시스템**

```
회피값 = floor((민첩-10)/2) + 1d10
회피 확률 = 회피값 / 200 × 환경 페널티
```
- **민첩 10 미만**: 회피 불가
- **중력 이상(gravity_anomaly)**: 회피율 **50% 감소**

---

### 4. **크리티컬 시스템**

| 항목 | 값 |
|------|-----|
| 기본 크리티컬 확률 | **10%** |
| 민첩 보너스 | `floor((민첩-10)/2) × 0.05%` |
| 크리티컬 데미지 배율 | **1.5배** |

---

### 5. **연계 공격 (Combo) 시스템**

같은 대상을 연속 공격 시 보너스:

| 연타 | 보너스 |
|------|--------|
| 2연타 | +10% |
| 3연타 | +20% |
| ... | ... |
| 9연타 | +80% |

- **9연타 초과 시**: 연계 끊기고 MP 회복 (열기: +10 MP)
- **5~8연타에서 끊김**: MP 회복 (잔열: +5 MP)

---

### 6. **난이도 & 플레이어 수 배율**

#### 난이도 배율
| 난이도 | 배율 |
|--------|------|
| 쉬움 | 0.7x |
| 보통 | 1.0x |
| 어려움 | 1.3x |
| 극악 | 1.6x |

#### 플레이어 수 배율
| 인원 | 배율 |
|------|------|
| 1명 | 0.6x |
| 2명 | 0.8x |
| 3명 | 1.0x |
| 4명+ | +0.1x씩 증가 |

**최종 몬스터 스탯 = 기본 스탯 × 난이도 배율 × 인원 배율**

---

### 7. **환경 효과 (20% 확률로 발동)**

| 효과 | 설명 |
|------|------|
| **마황 지대(lava_zone)** | 턴 종료 시 모든 참여자 최대 HP의 **3%** 피해 |
| **라이프스트림 폭풍(mana_storm)** | 턴 시작 시 모든 생존자 **+5 MP** |
| **중력 이상(gravity_anomaly)** | 회피 확률 **50% 감소** |
| **시간 왜곡(time_warp)** | 턴 순서 강제 셔플 |

---

### 8. **전투불능 & 부활**

- HP가 0이 되면 **is_dead = 3** (3턴 후 부활 가능)
- 전투불능 상태에서는 **힐 불가** (힐량 강제 0)
- DMW 에단 효과 등으로 is_dead를 0으로 만들면 힐 가능

---

### 9. **상태이상 시스템**

상태는 `status` 필드에 `상태명:지속턴:값` 형식으로 저장됩니다.

| 상태 | 효과 |
|------|------|
| **petrified (석화)** | 행동 불가 |
| **stunned/turks_stun** | 기절 |
| **tokura_death (죽음의 선고)** | N턴 후 즉사 |
| **stat_debuff** | 스탯 감소 |
| **geshtinn_invincible** | 무적 (데미지 0) |
| **isolde_protection** | 데미지 **50% 감소** |

---

### 10. **보스 스킬 시스템 (HP 트리거 기반)**

보스의 HP가 특정 %에 도달하면 스킬이 자동 발동됩니다:

| 효과 타입 | 설명 |
|-----------|------|
| **summon** | 몬스터 소환 |
| **damage_all** | 전체 공격 |
| **damage_mp_drain** | 데미지 + MP 흡수 |
| **lifesteal** | 데미지의 N% HP 회복 |
| **stat_debuff** | 스탯 감소/석화 |
| **buff_self** | 자기 강화 |
| **death_sentence** | N턴 후 즉사 |
| **instant_hp_one** | HP를 1로 만듦 |
| **rage** | 분노 모드 (공격력 증가) |

---

### 11. **공생 메커니즘 (특수 보스)**

**모체 식물(mid_boss_mother_flora)** 전용:

- **자동 치유**: 포자(spore_spreader)가 살아있으면 포자당 **+5 HP** 회복
- **공생 사멸**: 모체 사망 시 모든 포자 **동시 사멸**

---

### 12. **DMW (Digital Mind Wave) 시스템**

```
DMW 값 = round((매력-10)/2) + 4d10
```
- 일반 전투 성공 임계값: **35**
- 보스 전투 성공 임계값: **18** (약 2배 확률)
- **세피로스 발동 값**: 7

---

### 13. **리미트 브레이크 (직업별)**

| 직업 | 비용 | 효과 |
|------|------|------|
| **스트라이커** | HP 30% 소모 | 적에게 최대 HP 40% 데미지 (방어 무시) |
| **위버** | MP 30% 소모 | 아군에게 최대 HP 50% 힐 |
| **솔져** | HP 30% 소모 | 2~8회 다단 히트 |
| **턱스** | MP 30 소모 | 3턴 스턴 |
