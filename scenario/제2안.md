```
"내가 알고 싶거든?!"

"잠깐 나이트시티에 두고 온 게 있어서 귀환 프로토콜을 돌렸는데, 눈 떠보니 이 거지 같은 단말기 안에 데이터만 덜렁 박혀 있네.
이 열차 코어는 대체 구조가 어떻게 돼먹은 건지, 데이터 흐름이 완전히 엉망진창이야…."

### 몸은 어디 갔는데

```

"이상하잖아. 너희 같은 다른 승무원들은 차원 넘어갈 때 멀쩡히 고깃덩어리 달고 왔다 갔다 하잖아?
근데 왜 나만 몸뚱이가 온데간데없고 전뇌생명체처럼 단말기에 갇히냐고! 진짜 억울해 죽겠네!"
```

```
