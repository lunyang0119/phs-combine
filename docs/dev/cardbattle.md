# Card battle minigame (`cardbattle/`)

> Split out of [CLAUDE.md](../../CLAUDE.md). Keep this file up to date when the code changes.

Player/host/data/developer manual: [docs/cardbattle_guide.md](../../docs/cardbattle_guide.md). Same shape as the fugitive package: `engine.py` is pure Python (no Discord), `cog.py` is the thin Discord layer, `store.py` keeps `data/cardbattle_state.json`, `sim.py` is the balance check (`python -m cardbattle.sim --all --games 200`, or `--battle bonewa4 --players 4 --set ncpd_max=4`). The shipped data is a Cyberpunk 2077 TRPG session: three scripted boss fights, 스캐빈저 (`scav3`…`scav7`, one id per headcount), 고장난 돌 (`doll3`…`doll7`) and 몸의 보느와 (`bonewa3`…`bonewa7`), plus the six-round tutorial `tut` and a gimmick-free practice `b01`. Sheet columns keep the FF7 names; only the display strings are Cyberpunk (`strings.STAT_KO` 마력→RAM, `JOB_KO` 스트라이커→엣지러너 / 마테리아 위버→넷러너). Every in-battle sentence (intro rules `INTRO_RULES`, 💡 tips `TIPS`, mode text, boss endings, coach text in `Tutorial.csv`) lives in `strings.py` / the CSVs so the GM can re-tone it.

- One session at a time (`CardBattleCog.state`). `/카드` with no `옵션` answers with an ephemeral button menu (`views.MenuView`, one button per `OPTION_CHOICES` entry → `cog.handle_menu`); its 시작 button opens a battle dropdown (`BattleSelectView` → `handle_battle_pick`, battles matching the lobby headcount first, max 25). The typed form still works: `/카드 옵션:주최|참가|시작|턴종료|종료|현황|금고|규칙|관리자` with optional `전투id` and `금액` (no required options, see `tests/test_help_option.py`). `옵션:주최` replies ephemerally and makes the caller the session's host. Everyone, host included, draws a random hand; `옵션:관리자` (host or `CARDBATTLE_ADMIN_IDS`, must be a participant) toggles the caller into `BattleState.all_cards` so `engine.admin_sees_all` shows the whole pool for this battle only (carried from lobby into the started battle; `admin_sees_all=true` in config restores the old always-on host behaviour, which the test fixtures rely on). `옵션:참가` edits the single lobby message; player stats come from the Characters sheet via `get_char_data` (mapping lives only in `engine.player_combatant`, which also reads `job` and `color`), the displayed name is the Discord server nickname. `옵션:시작 전투id:X` loads `data/cardbattle/{Cards,Enemies,Battles,Tutorial}.csv` through `data.make_source` (or sheet tabs, see Environment), applies the battle's `overrides` column on top of the session config (`enemy_hp_mult`, `ncpd_max`, `chip_stability`, `firewall_options`, `modes` … — this is how headcount is balanced; list values inside `overrides` use `,` because `;` splits the pairs, `engine.split_list` accepts both), and snapshots the cards (and the tutorial script) into the state. A row whose id starts with `#` is a comment: hidden from the bot, but `load_game_data(include_commented=True)` (used by the tests, the cog test harness and `sim.py` unless `--visible-only`) still loads and validates it. `옵션:규칙` sends `strings.HELP_SECTIONS` as ephemeral embeds (`embeds.chunk_embeds`); `S.HELP` must stay short enough for `help_option.render_help`'s 2000-char cut.
- **Gig economy (`gig.py`).** With `prep_enabled` (default) `new_battle` stops in status `PREP`: every player gets a random weapon (`Combatant.weapon_grade` 1–2, name from `strings.WEAPON_NAMES` passed in as `weapon_names=`), the team pot (`data/cardbattle_gig.json`, the only state that outlives a battle; `gig.load_pot/set_pot`) is split equally into `st.prep["allowance"]`. The persistent `PrepView` buttons (`cardbattle:prep:normal|black|ready`) call `gig.prep_upgrade` (정식: pay `price_normal`, +1 up to `weapon_normal_max`; 뒷골목: `price_black`, `engine.roll_upgrade` d10 — 1→2 automatic, ≤`gamble_fail_max` drops one grade, a 1 drops `gamble_fumble_drop`, a 10 refunds; only route to `weapon_max`) and `gig.prep_ready`; `gig.finish_prep` returns unspent allowance to `meters["pot"]` and calls `engine.begin_combat`. `weapon_bonus` (`0;3;6;10`) is added to every damage card the ally plays (`_h_damage`, `damage_range`, `expected_damage`). While `meters["pot"] >= field_mod_cost` the `fixed` card `field_mod` is in the hand: it costs the action, success +1 grade, failure never downgrades but adds `misfire`. At `ENDED` `_after_round` calls `gig.apply_payout` (idempotent via `meters["payout"]`; `reward_per_player × players × ratio − penalty_overkill·overkills − penalty_loud·loud`, plus the leftover pot, written back to the file unless `prep_sandbox`). Weapons are never persisted. Test fixtures set `prep_enabled=False`; cog tests point `cog.gig_path` at a temp file.
- **Rounds, not half-turns.** `open_round` makes every enemy choose first (`enemy_choices`) and publishes only the card **kind** in `intents` (`public_intents` adds the target only with `show_intent_target` or the round's `scan` flag). Players then choose; `resolve_round` resolves **both sides together**: phase (hack 0 → defend 1 → attack/special 2) → agility desc → random, so a fast hacker's stun cancels a slower enemy's attack in the same round. `shield` and `daemon` tick at the end of every round including the creation round (`shield:0.5:1` = this round only); `atk_down`/`misfire`/`redirect_random`/`stun` are ONE_SHOT: `atk_down` is consumed once per damage card in `_apply_card` (a misfired or evaded attack keeps it), `stun` is announced at the top of the round and removed at its end (so "기절한 적에게" combos work all round); `grapple` is removed only by 떨쳐내기, an ally hit on the doll, or the firewall reboot. Unchosen players "대기". There is no timer.
- The public round message carries two persistent buttons (`cardbattle:draw`, `cardbattle:firewall`) and, when Pillow + a CJK font are present (`render_mode=image`, checked by `cog._image_mode()`), the `image_render.render_board` PNG as the embed image (`attachment://board.png`; editing the embed alone keeps the attachment). `image_render` reuses `fugitive.image_render`'s font lookup and colour parsing, so the fugitive package must stay importable even while its cog is off. Ally panel colours come from the Characters `color` column, enemy colours from `Enemies.csv`. Hand and target menus show **⚠ 과잉 위험** from `engine.overkill_risk` (max damage incl. combo, weapon, steady aim and ICE vs `overkill_margin` 15; `lethal` cards whenever they can down the target, `nonlethal` cards never).
- **Gimmicks** (`Battles.csv` `gimmicks`, constants in `engine.GIMMICKS`): `nonlethal` (downing an enemy with `dmg - hp >= overkill_margin`, or with a `lethal`-tagged card, is 과잉 제압; `nonlethal`-tagged cards are exempt; `meters["last_ko"]` remembers the finishing card), `ncpd` (과잉 제압 +1, ally `loud` cards +0.5; at `ncpd_max` the fight ends and `start_escape` begins the 5-turn rock-paper-scissors: `ESCAPE_BEATS`/`ESCAPE_LOSES`, police action pre-rolled per turn with one excluded action published as a hint when `escape_hint`, a turn is won when `wins*2 > n` living players, alert starts at `escape_wins_needed` and hits 0 = `ESCAPED`, out of turns = `CAUGHT`), `drag` (a downed player is dragged by a random living enemy; after `drag_turns` rounds `Combatant.looted` is set unless the dragger is downed or the player revived), `doll` (enemy with trait `doll`: acts by mode from `doll_modes` instead of the AI, never stunned (stun → extra chip damage), `meters["chip"]` drops `chip_per_hack` per ally hack hit capped by `chip_round_cap` per round (×`chip_reboot_mult` while rebooting); chip 0 = ally win with `end_reason="chip"`), `terminal` (`meters["terminal_holder"]` is the doll's only target; the holder always has the `fixed`-pool card `pass_terminal`; `meters["screen"]` drops when the holder takes damage), `first_strike` (after prep, `resolve_ambush` plays `first_strike_cards` for every enemy as round 0 with no player actions, ticks, end checks or life tick; the report goes to `st.pending_reports` and the cog posts it before the first turn), `daemon` (modifier `daemon`, value = stacks summed by `add_modifier`, TICKING `daemon_turns`; `_daemon_bite` after `_apply_card` hurts an infected unit `daemon_damage × stacks` when it plays any card in a round after the one it was infected in; `daemon_max_infected` caps simultaneous victims, extra infections stack on existing ones; removed by `cleanse` (보느와의 ICE) or the firewall reboot), `ice` (`meters["ice"]` layers; damage to enemies × `max(0.1, 1 − ice_reduction·layers)`; each ally hack hit strips one layer up to `ice_round_cap` per round; `expose` effect clears it), `firewall_duel` (intro text only — the `firewall_drain`/`firewall_lock` effects work regardless; a lock sets `meters["firewall_lock_round"] = round+1` because `round_flags` are wiped by `open_round`), `life_support` (`meters["life"]` −1 per round after `_advance_drag`, −1 more on `expose`; 0 after the KO checks = ally win `collapse`; ally wins record `meters["boss_state"]` fine/hurt/critical from `last_ko`), `tutorial` (script snapshot in `BattleState.script` from `Tutorial.csv`; `tutorial.chooser` scripts the enemies, `guaranteed` cards are forced into every hand in `draw_hand`, `apply_setup` runs in `open_round`, `evaluate` fills `report["tutorial"]`, enemies cannot drop below 1 HP before the last scripted round, and the last round ends the fight with `end_reason="tutorial"`). Enemy `traits` (`cheap_chrome` hack values ×`hack_weak_mult`, `evade` vs physical single-target damage, `regen` per round, `modes` = acts by the battle's `modes` table like the doll, `modes_norepeat` forbids repeats; one mode-driven enemy per battle, key `meters["doll_mode"]` + `meters["mode_owner"]`) live in `Enemies.csv`. Bonewa battles have no `ncpd`.
- **Special rules ported from `combat/`** (six more `GIMMICKS`; not in `tut` or `b01`). They have no `INTRO_RULES` line (the intro's rules field is capped at 1000 chars); instead `embeds.intro` adds a "특수 규칙" field naming them and `cog._begin_messages` posts `embeds.briefing(st)` once before the first turn message (`render.briefing_sections` fills `strings.BRIEFING[gimmick]` with config numbers; guarded by `meters["briefed"]`, off with `briefing=false`). Any gimmick key added to `BRIEFING` gets a section. `limit`: `engine.limit_card_for` maps `Combatant.job` through `limit_cards` (`job:card;…`, `*` fallback) to a `fixed` card tagged `limit`; `fixed_cards` hands it out until the player's id is in `meters["limit_used"]` (set at the top of `_apply_card`, so a misfire still spends it). Tag `pierce` skips shield, ICE and evade. Effect `flurry:value:max` (a `COUNT_KINDS` entry) rolls 2..max hits into one damage instance; `damage_range`/`expected_damage` go through `_card_base`. `flash` (the DMW analogue): `open_round` ends with `_roll_flash` (round ≥ 1): each acting player rolls 4d10 + `flash_bonus` (`(charm-10)//2`), the top `flash_per_round` rolls ≥ `flash_threshold` get one of `FLASH_EFFECTS` that currently applies (`_flash_options`); records go to `meters["flash_now"]` (cleared every `open_round`) and `cog._open_turn` posts `embeds.flash(st)` right above the turn message. Figures and dialogue live in `strings.FLASH_FIGURES` (one per effect; `memories` is a list of line groups, picked by the record's `line` index so `render` needs no rng; the shipped lines are placeholders for real session RP quotes). `boost` is a ONE_SHOT modifier consumed by the next damage card; `flash_extra` lives in `round_flags`. `chain`: `round_flags["chain"][target_id]` counts ally damage hits this round; later hits get `chain_bonus` per prior hit (cap `chain_max`), the `chain_firewall_at`-th adds firewall; overkill is judged on `base_dmg` without the chain bonus so ⚠ stays honest. `phases`: config `phases=enemy_id:hp%:card_id` (validated in `data.py`); `_check_phases` (end of `resolve_round`) queues the card in `meters["phase_queue"]` and emits a `phase_warn` event, `open_round` then plays it with intent kind `phase` (a stunned enemy keeps it queued); effect `rage:value` is a permanent damage-multiplier modifier. `talk`: `fixed` card `talk` (`TALK_CARD`, `stat=charm`), `_h_talk` rolls 2d10 + `charm // stat_divisor` vs `talk_dc` (+`talk_dc_step` per earlier attempt on that target, `meters["talk_count"]`); success adds `atk_down`, and life +1 / ncpd − / chip − depending on the battle's gimmicks, a crit adds `stun`; `card_phase` resolves it in phase 0; the enemy's reply comes from `strings.TALK_LINES[enemy_id]` by the `quote` index. `env`: `new_battle` rolls `meters["env"]` from `env_pool` (`ENVS`: `blackout` hides `public_intents` unless scanned, `emp` adds firewall each round, `acid` chips everyone at round end but never below 1 HP, `glitch` zeroes the agility sort key). Tests: `tests/test_cardbattle_special.py`.
- **보느와의 방화벽** (`meters["firewall"]`, always on): +1 per `firewall_per_damage` ally damage taken, +`firewall_per_defend` per ally defend card, +`firewall_per_down`; `use_firewall(st, uid, option)` once per round (`round_flags["firewall_used"]`), options in `engine.FIREWALL_OPTIONS` (`cover` team shield, `reboot` clears debuffs/grapple/stun/daemon, `aim` zero variance + ignores evade this round, `scan` reveals intent targets, `maxdoc` heals/revives the worst ally) but only those in the battle's `firewall_options` (`engine.enabled_firewall_options`; default `cover;reboot;maxdoc`, scav adds scan, doll aim, bonewa all; `FIREWALL_OFF` / `FIREWALL_LOCKED` rule errors). Round-scoped flags live in `round_flags` and are wiped by `open_round`.
- Every public message is a `discord.Embed` built in `embeds.py` from the sentences `render.py` produces; `render.py` stays Discord-free. The round report is one embed with 🟢/🔴 per line in true resolution order, then event lines (`render.event_line`), then 💡 tip lines (`render.tip_lines` from `report["tips"]`, keys detected once per battle by `engine._collect_tips` into `meters["tips_seen"]`, off with `tips=false`), then the tutorial ✅/❌ line. Log line format is `strings.LOG_USE` + `LOG_TARGET`: `<닉네임>님이 <카드>을(를) 사용했습니다. <대상> HP x/y (-n)`; the HP is the **target's**, the target name is omitted when it is the actor; `⚡콤보!` / `(적대 인식!)` prefixes, `⚠과잉 제압` / `💾칩 −n` / `🧊ICE −n` / `🦠데몬 −n` / `🪢… 풀려남` suffixes. Enemy AI (`ai.py`) scores each drawn card with a personality weight table plus `ai_noise`, damage scaled by `DMG_SCALE` so attacks and hacks share one scale; no LLM.
- Cards are data: `effects` is `kind[:value[:turns[:chance]]]` joined by `;` (kinds in `engine.EFFECT_KINDS`; for `COUNT_KINDS` = `scatter_damage`/`daemon` the third slot is the random target **count**, stored in `Effect.count`), `tags` is `loud`/`lethal`/`nonlethal`, `combo` is `target_has|self_has:<modifier>:dmg_x|dmg_add|chip_add:<value>` and is rendered automatically into the card description (`render.combo_text`) and the log. `pool=fixed` cards are never drawn; `engine.fixed_cards` hands them out (`pass_terminal`, `break_free`, `field_mod`, the mode and ambush cards). New balance numbers go in `cardbattle/config.py` `DEFAULTS` (also the only place `Battles.csv` `overrides` keys are validated).
- `sim.py` uses the real job templates (엣지러너 HP 110 근력 16 / 넷러너 HP 80 RAM 16 / 솔져), plays the prep phase per policy (greedy 정식, attack_only 뒷골목, random), and always prints `greedy`, `attack_only` and `random` side by side with mean weapon grade, reward and 보느와 state: if `attack_only` matches `greedy`, non-attack cards are traps. Battle `overrides` are applied automatically; `--set` overrides them.
- The engine takes an `rng` argument (any object with `random/randint/choice/choices`); the default adapter wraps `combat.random_utils` lazily. Note `random_utils.get_random()` itself is broken (`_rng.get_random`), so the adapter uses `uniform`. `engine` never imports `strings`, `gig` or `tutorial` at module level (`tutorial`/`ai` are imported lazily inside functions).
- Tests: `tests/test_cardbattle_engine.py` (round order, modifiers, every classic gimmick, firewall, escape, combo), `test_cardbattle_gig.py` (weapons, prep, field mod, payout, ⚠, firewall options, stun combo), `test_cardbattle_boss.py` (daemon, ICE, firewall duel, life support, ambush, modes, tips, tutorial), `test_cardbattle_ai.py`, `test_cardbattle_cog.py` + `test_cardbattle_cog2.py` (fake channel/interaction harness incl. prep buttons, firewall menu, scan, NCPD → escape buttons, restart, vault/rules commands, bonewa ambush, tutorial coach, ⚠ target labels). `/카드` must stay a single class-level command with no required options so `tests/test_help_option.py` keeps passing. Copy `cardbattle/` and `data/cardbattle/` to `local_server/` after changes.

## Environment

- `CARDBATTLE_SOURCE` (`csv`, default, or `sheet`), `CARDBATTLE_DATA_DIR` (default `data/cardbattle`), `CARDBATTLE_ADMIN_IDS` (falls back to `FUGITIVE_ADMIN_IDS`; may force-resolve or end any card battle) — card-battle minigame data source and override admins. With `sheet`, tabs `Card_List` / `Card_Enemies` / `Card_Battles` / `Card_Tutorial` (same columns as the CSVs) are read, falling back per table to the CSVs with a warning. The team pot (에디) persists in `data/cardbattle_gig.json` (gitignored)
